Kriteria penerimaan

acceptance

  • Aplikasi menolak input kosong dan format file yang tidak sesuai.
  • Aplikasi menjalankan model YOLOv8 setelah gambar valid diterima.
  • Aplikasi menampilkan bounding box, label jenis Plasmodium, dan nilai confidence.
  • Aplikasi menyediakan unduhan hasil deteksi.
